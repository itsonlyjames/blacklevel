Level

Black level is the line a picture sits on. Below it, nothing. Above it, everything. The icon is that line and nothing else, placed on the golden section so it feels set, not centred.

From 64 px down each size is redrawn, not shrunk: the line gets thicker and the glow stronger so it stays one crisp pixel row at 16. Below the line is darker than the field above it, so even unlit the icon has a horizon.

Remote · menu bar, TV off and on

The Remote's menu bar icon already changes with the TV (it uses the system tv and tv.fill today). Each glyph keeps that: off is just the line, on lights everything above it, and below stays empty either way. These are template images, one colour plus alpha, so macOS tints them for light and dark bars.
